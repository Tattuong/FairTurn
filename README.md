# FairTurn

Fair turns for a group. Not bill-splitting, and not a chore checklist. The app answers “Whose turn is it?”

Package: `com.FairTurnMNG.FairTurn`

Remote config: [N299.json](https://api2.blwsmartware.net/N299.json) — `disable=1` hides Google Play Billing popups only. The shop still spends coins.

| Product ID | Type |
| --- | --- |
| `ft_pack_1` … `ft_pack_10` | Consumable coins |
| `ft_remove_ads` | Non-consumable |
| `ft_pro` | Non-consumable |

Create a group, mark who is here, and confirm the next turn. The pick is the present person with the fewest completed turns. A tie goes to whoever has waited longest. Skips and absences are not counted. History stays on this device. No account.
